Data Structures Simulator

A web applicstion currently in development and design. Will simulate, display, time various data structure operations and algorithms. These algorithms will inclufe Djikstra's shortrst path, Kruskal's, Prim's minimum spanning tree, and various sorting algorithms starting from easy to harder ones.

Will utilise Java Springboot, React, and  some JNI for C++ logic code. The extent to which the C++ JNI code will depend on how hard it is to implement.
